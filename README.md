🎓 Academic Management System

"🌐 Visit Live Website" (https://academic-management-system-meqt.onrender.com/)

A web-based Academic Management System designed to simplify academic activities and improve communication between students and teachers through dedicated portals.

📌 Project Overview

The Academic Management System is a centralized web application that provides students and teachers with dedicated interfaces to manage and access academic information.

The platform consists of two main portals:

- Student Portal – Allows students to access their academic information, attendance, assignments, timetable, study materials, and notices.
- Teacher Portal – Provides teachers with tools to manage academic activities, student information, attendance, assignments, and learning resources.

The goal is to make academic management more organized, accessible, and efficient.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

git clone https://github.com/harlivk/academic-management-system.git

2. Navigate to the Project Directory

cd academic-management-system

3. Install Dependencies

pip install -r requirements.txt

4. Apply Database Migrations

python manage.py migrate

5. Start the Development Server

python manage.py runserver

6. Open in Browser

Visit:

http://127.0.0.1:8000/
